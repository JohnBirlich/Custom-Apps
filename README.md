# UUF — Universal Username Finder

UUF — приложение для Windows, которое придумывает никнеймы и проверяет их доступность на популярных платформах. Программа собирает кандидатов из нескольких источников (словари категорий, выдуманные слова, случайные наборы символов, замена букв цифрами), проверяет их в несколько потоков и показывает понятный результат: свободен, занят, недопустим или требует подтверждения.

Приложение с открытым исходным кодом. Весь код лежит в этом репозитории: один скрипт `UniversalUsernameFinder.ps1`, тесты `tests/`, сборка в `.exe` через `build/` и документация, которую вы читаете.

## Что умеет

- Генерация ников из 44 единых категорий, своих слов-якорей, выдуманных слов и сочетаний, редких коротких форм, случайных наборов символов и leet-замен (`Void` → `V01d`).
- Проверка доступности на платформах: Roblox, Google (Gmail), Mail.ru, VK, Discord, Outlook, Telegram, Steam, GitHub, YouTube. Для Steam проверяется публичный адрес `steamcommunity.com/id/<ник>`: занятость vanity-адреса не равна занятости логина аккаунта.
- Почтовые платформы показывают и проверяют ник как адрес: `ник@gmail.com`, `ник@mail.ru`, `ник@outlook.com`.
- Многопоточная проверка (до 8 потоков, рекомендовано 2–4) с общей очередью, адаптивной паузой и оценкой оставшегося времени под полосой прогресса.
- Постоянный список проверенных ников: повторы исключаются даже после перезапуска программы; окно «Проверенные ники» позволяет повторно проверить или удалить записи.
- История свободных ников: фильтр по платформам (галочки) и сортировка — по платформе и дате генерации, просто по дате или по нику; повторная проверка в один клик.
- Генератор паролей по стандартам защиты: заглавные и строчные буквы, цифры и спецсимволы.
- Окно регистрации под текущую платформу: сайт открывается в режиме инкогнито, ник и пароль соответствуют выбранному сервису.
- Хранилище паролей защищено Windows DPAPI и доступно только текущему пользователю.

## Интерфейс

Интерфейс — тёмная тема: сине-фиолетовые акценты на графитовом фоне, стандартная рамка окна Windows со скруглением через DWM (Windows 11). Логотип приложения используется везде: в заголовке окна, в панели задач и диспетчере задач (иконка `assets/uuf.ico` встроена в `UUF.exe`), в шапке и в окне помощи; растровые версии логотипа и иконки встроены в скрипт base64, поэтому интерфейс выглядит одинаково даже без папки `assets` рядом с `exe`. Анимаций запуска и наведения нет — окно открывается сразу.

При каждом запуске выставлен стандартный набор: все категории, стиль «без стиля», 40 ников длиной 3–25, однословные ники, редкие короткие, выдуманные слова, случайные символы, исключать проверенные, только короткие, пауза 700 мс, 2 потока. Всё остальное выключено — можно просто запустить и нажать одну кнопку.

## Запуск

1. Скачайте релиз или клонируйте репозиторий.
2. Запустите `UUF.exe` (после сборки лежит в `dist\`) — PowerShell не нужен.
3. Либо откройте `UniversalUsernameFinder.ps1` в Windows PowerShell 5.1; если политика выполнения запрещает скрипты, разово выполните `Set-ExecutionPolicy -Scope Process Bypass`.

## Сборка .exe

Сборка выполняется модулем [ps2exe](https://github.com/MScholtes/PS2EXE): `build\Build-Exe.bat` или `build\Build-Exe.ps1`. Результат — `dist\UUF.exe` с иконкой приложения. `.exe` встраивает скрипт в открытом виде (извлекается параметром `-extract`), поэтому это оболочка запуска, а не защита кода; источник правды — `.ps1`.

## Тесты и CI

Тесты Pester лежат в `tests/UniversalUsernameFinder.Tests.ps1` и запускаются локально и в GitHub Actions. Прогон CI разбирает скрипт парсером в Windows PowerShell 5.1 и PowerShell 7, проверяет кодировку UTF-8 BOM, прогоняет PSScriptAnalyzer и тесты, собирает `.exe` и проверяет встроенный скрипт извлечением.

## Структура репозитория

- `UniversalUsernameFinder.ps1` — всё приложение: словарь, генератор, интерфейс, воркеры проверки.
- `tests/UniversalUsernameFinder.Tests.ps1` — тесты Pester.
- `build/` — сборка `.exe` через ps2exe.
- `assets/` — логотип и иконка.
- `.github/workflows/ci.yml` — прогон CI.
