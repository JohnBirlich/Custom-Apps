UNIVERSAL USERNAME FINDER v2.5
Windows 10/11 x64 • Windows PowerShell • требуется интернет-соединение

ИЗМЕНЕНИЯ v2.5
- Сохранение зашифрованного хранилища использует временный файл и уникальный резервный файл с абсолютными путями. Исправлена причина ошибки File.Replace с недопустимым путём резервной копии.
- Проверки платформ разбирают только распознаваемые ответы; неизвестный или блокируемый ответ отмечается как «Не подтверждено», а не считается свободным.
- Для endpoint-ов с публичным профилем используется осторожный статус «Вероятно свободен», поскольку отсутствие профиля не гарантирует возможность регистрации.


ЗАПУСК
1. Распакуй весь ZIP-архив в папку.
2. Запусти Start.bat.
3. Выбери платформу и одну или несколько смысловых категорий.
4. Настрой длину, количество, префикс/суффикс и фильтры.
5. Нажми «Сгенерировать и проверить». Генерация автоматически запускает последовательную проверку.

ПЛАТФОРМЫ
Roblox, Google/Gmail, Mail.ru, VK, Discord, TikTok, Microsoft/Hotmail, Outlook, Telegram, GitHub, YouTube и Apple.

ЕДИНЫЕ КАТЕГОРИИ
Цельные слова, короткие ники, космос, свет и энергия, природа, мифология, эмоции, скорость, абстрактные и эстетичные имена. Названия приложений и брендов не используются как отдельные категории.

СТАТУСЫ
- «Свободен» — доступность подтверждена ответом валидатора или API на момент проверки.
- «Вероятно свободен» — публичный профиль/handle не найден; имя всё ещё может быть зарезервировано или недоступно при регистрации.
- «Занят» — платформа сообщает, что имя занято, или найден профиль.
- «Не подтверждено» — запрос был выполнен, но сервис не раскрыл однозначный ответ (например, из-за антибот-защиты или изменения внутреннего интерфейса). Это не означает, что имя свободно.
- «Ошибка сети» — запрос не завершился из-за соединения, тайм-аута, лимита запросов или серверной ошибки. Нажми «Повторить ошибки» позже.
- «Недопустимый» — имя не соответствует локальным правилам длины/символов или отклонено валидатором.

ПЛАТФОРМЕННЫЕ МЕТОДЫ
- Roblox — публичный валидатор имён Roblox.
- Google — запрос регистрации Gmail с текущей регистрационной сессией и разбором ответа проверки имени. Внутренний формат Google может меняться.
- Mail.ru — endpoint существования адреса @mail.ru.
- VK — API разрешения screen name и fallback на публичную страницу профиля.
- Discord — endpoint проверки уникального username; ограничения Discord могут ответить 429/403.
- TikTok — разбор публичной страницы @handle; антибот-защита может не дать ответ.
- Microsoft — проверка @hotmail.com; Outlook — проверка @outlook.com через регистрационную сессию signup.live.com.
- GitHub — публичный API профилей. HTTP 404 означает «Вероятно свободен», а не гарантию доступности.
- YouTube — разбор публичной страницы канала @handle; отсутствие канала не гарантирует, что handle можно присвоить.
- Telegram — проверка публичной страницы t.me. Полная проверка доступности для аккаунта через MTProto требует авторизованной сессии; поэтому неясный ответ отмечается как неподтверждённый.
- Apple — Apple Account использует адрес электронной почты, а не универсальное имя пользователя. Анонимного публичного API проверки свободного Apple Account нет, поэтому программа не объявляет такие имена свободными без подтверждения.

Это автоматические сетевые проверки, но не каждая платформа раскрывает анонимному клиенту окончательную доступность. Программа не использует CAPTCHA solving и не пытается обходить защитные проверки. Если endpoint не выдал проверяемый ответ, она показывает «Не подтверждено», а не ложное «Свободен».

ИСТОРИЯ СВОБОДНЫХ НИКОВ
Кнопка «Свободные ники» открывает историю в формате «Ник — Платформа». «Повторная проверка» запускает тот же метод для указанной платформы. Если ник теперь занят, он удаляется из истории и добавляется в локальный список исключённых имён. История хранится в %LOCALAPPDATA%\UniversalUsernameFinder\username_history.json.

СОХРАНЕНИЕ АККАУНТОВ
Пароли хранятся в зашифрованном хранилище с использованием Windows DPAPI текущего пользователя. Для записи используется временный файл и атомарная замена с backup-файлом, чтобы повторное сохранение и удаление не вызывали ошибку из-за пустого пути резервной копии. Если файл заблокирован системой, подробность попадёт в UniversalUsernameFinder.log.

ЭКСПОРТ И УДОБСТВО
Двойной щелчок по свободному/вероятно свободному имени копирует его. TXT сохраняет свободные и вероятно свободные варианты, CSV — все результаты. Есть фильтры, поиск, сортировка, прогресс, журнал, остановка проверки и повтор сетевых ошибок.

ЛОГИ
UniversalUsernameFinder.log — диагностический журнал.
startup_error.log — ошибки запуска Start.bat.

Доступность имени может измениться после проверки; окончательное решение принимает сама платформа во время регистрации. ZIP содержит PowerShell-скрипт и не требует установки Python или сторонних библиотек. GUI нельзя проверить в среде сборки без Windows PowerShell/WinForms; при ошибке пришли startup_error.log или UniversalUsernameFinder.log.
